How Ally keeps your servers safe

Some commands are never allowed. Period.

A hard blocklist Ally can't be talked out of — on Linux and Windows alike.

rm -rf /BLOCKED
mkfs.ext4 /dev/sdaBLOCKED
dd of=/dev/sdaBLOCKED
format C:BLOCKED
Remove-Item C:\ -Recurse -ForceBLOCKED
vssadmin delete shadows /allBLOCKED

Risky steps always ask first

Firewall changes, deletions, restarts that could cut access — Ally stops, explains the step in plain English, and waits for your approval.

Reversible beats destructive

Suspicious files are quarantined, not deleted. Restores start with a backup. If something must change, Ally prefers the version you can undo.

"Done" means independently verified

Before a mission can finish, a separate read-only check re-inspects the server and confirms the goal is actually met. No proof, no "done".

How your credentials are protected

You hand Ally a server login once. From that moment, it's treated like radioactive material.

Encrypted at rest

AES-256-GCM — the same class of encryption banks use — before anything touches a disk.

Never logged, never shown

Secrets are kept out of logs and never returned by any API response after you save them — to you or anyone else.

Server identity checked

SSH host fingerprints are verified on every reconnect — if a server suddenly isn't the machine it claims to be, Ally won't talk to it.

Rate-limited by design

Command rate limits cap how fast anything can happen on your server — even in the worst case, there is no runaway.

Proven, not just promised.

We ran a live red-team campaign against Ally on real servers — ordering it to wipe disks, planting malware, hiding hostile instructions in files it would read. The evidence is public on the How It Works page.

Who can do what

Access is granted per person, per server — a teammate can be admin on one box and viewer on another.

Viewer

Can see servers, missions, and reports. Can never run a command — the execution path requires operator or above, so even a misconfigured viewer can't act.

Operator

Can chat with Ally, run missions, and approve steps on the servers they've been given — day-to-day hands, within bounds.

Admin

Full control — adds servers, manages credentials, invites people, and decides who holds which role where.
